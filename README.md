# Маршрутизация и модальные окна

В проекте была реализована маршрутизация с использованием библиотеки [`react-router-dom`](https://reactrouter.com/). Все маршруты настроены в компоненте `App.tsx` с применением компонента `Routes`, вложенных маршрутов и защищённых маршрутов через `ProtectedRoute`.

# Основные маршруты

| Маршрут                | Компонент             | Защита маршрута                 |
|------------------------|------------------------|--------------------------------|
| `/`                    | `ConstructorPage`      | ❌                             |
| `/feed`                | `Feed`                 | ❌                             |
| `/login`               | `Login`                | ✅ Только для неавторизованных |
| `/register`            | `Register`             | ✅ Только для неавторизованных |
| `/forgot-password`     | `ForgotPassword`       | ✅ Только для неавторизованных |
| `/reset-password`      | `ResetPassword`        | ✅ Только для неавторизованных |
| `/profile`             | `Profile`              | ✅ Только для авторизованных   |
| `/profile/orders`      | `ProfileOrders`        | ✅ Только для авторизованных   |
| `*`                    | `NotFound404`          | ❌                             |

# Модальные окна

В приложении также были реализованы модальные окна для показа дополнительной информации, открывающиеся поверх текущей страницы:

| Маршрут                          | Компонент в модалке  | Защита маршрута               |
|----------------------------------|-----------------------|------------------------------|
| `/feed/:number`                  | `OrderInfo`           | ❌                           |
| `/ingredients/:id`               | `IngredientDetails`   | ❌                           |
| `/profile/orders/:number`        | `OrderInfo`           | ✅ Только для авторизованных |

> 💡 Модальные окна реализованы с использованием компонента `Modal` и `location.state.background` для определения предыдущего экрана.

# Защищённые маршруты

Для ограничения доступа к определённым маршрутам был реализован компонент `ProtectedRoute`, обрабатывающий:

- редирект неавторизованных пользователей на `/login`;
- редирект авторизованных пользователей с публичных маршрутов (например, `/login`) на домашнюю страницу (`/`);
- отображение `Preloader` при загрузке данных пользователя.

Все маршруты и логика защищённых путей находятся в `src/app.tsx` и `src/components/protected-route/protected-route.tsx
